# Game On Platform

🎮 A competitive gaming and betting platform built with React Native & Node.js

## 🚀 Quick Start

### Features
- 8 Ball Pool (MVP)
- 1v1 Real-time Games
- Tournament System (Best 3, Best 2, Best 1)
- 4v4 Team Battles with Live Substitutions
- Play Money Testing → Real Money Betting
- Tier-Based Matchmaking
- Nigeria-Focused (Flutterwave Payments)

### Tech Stack
- **Mobile:** React Native (Expo) - iOS & Android
- **Backend:** Node.js + Express + TypeScript
- **Database:** PostgreSQL
- **Real-time:** Socket.io
- **Payments:** Flutterwave API

### Project Structure
```
game-on/
├── backend/              # Node.js backend
├── mobile/               # React Native app
├── admin/                # Admin dashboard (web)
├── docs/                 # Documentation
└── README.md
```

## Get Started

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### Mobile App Setup
```bash
cd mobile
npm install
npm start
# Scan QR code with Expo Go app
```

### Admin Dashboard Setup
```bash
cd admin
npm install
npm start
```
